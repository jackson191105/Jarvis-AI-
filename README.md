# Jarvis AI Assistant

A futuristic Jarvis AI assistant built using:

- HTML
- CSS
- JavaScript

## Features

- Voice Recognition
- AI Responses
- Speech Synthesis
- Open Websites
- Search Google
- Modern UI
- Mobile Responsive

## How to Run

1. Download files
2. Open folder in VS Code
3. Install Live Server extension
4. Right click index.html
5. Click Open with Live Server

OR

Upload to GitHub and enable GitHub Pages.

## Commands

Try saying:

- Hello
- What is the time
- Open Google
- Open YouTube
- Search AI technology
- Play music
- Tell me a joke
